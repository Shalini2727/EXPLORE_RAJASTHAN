# Explore Rajasthan

Explore Rajasthan is a responsive tourism website developed to showcase the culture, heritage, tourist destinations, traditional food, and attractions of Rajasthan.

## Features

- Rajasthan tourist destinations
- Historical and cultural attractions
- Information about traditional Rajasthani food
- Responsive and user-friendly interface
- Mobile-friendly design
- Image and video-based destination sections
- Easy navigation between different sections

## Technology Stack

- **HTML5** – Website structure
- **CSS3** – Styling and responsive design
- **JavaScript** – Interactive functionality
- **Responsive Web Design** – Mobile and desktop compatibility
- **Images & Videos** – Destination and tourism content
