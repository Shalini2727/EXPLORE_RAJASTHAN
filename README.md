# Explore Rajasthan

Explore Rajasthan is a responsive tourism website designed to showcase the
culture, heritage, attractions, food, and destinations of Rajasthan.

## Features

- 🏰 Rajasthan tourist destinations
- 🕌 Historical and cultural attractions
- 🍛 Information about traditional Rajasthani food
- 🎨 Responsive and user-friendly interface
- 📱 Mobile-friendly design
- 🖼️ Image and video-based destination sections
- 🧭 Easy navigation between different sections

## Technology Stack

- Frontend: HTML5, CSS3, JavaScript
- Design: Responsive Web Design
- Media: Images and Videos
